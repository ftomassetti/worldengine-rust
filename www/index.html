worldengine

a Rust + WebAssembly port of the Python worldengine generator, on top of the ported plate-tectonics library

World

`.world` files use worldengine's own protobuf format, so they interchange with the Python tool.

Plate tectonics dominates generation, and its cost grows with the square of the map side. Plate detail ÷ runs it at a fraction of the world size and expands the result, which is why 512×256 now finishes in a fraction of a second rather than around twenty. It generates no structure below plate scale anyway; the later stages supply that detail. Set it to 1 for full-resolution tectonics.
